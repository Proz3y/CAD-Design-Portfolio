# Phone Holder Design

## Project Overview
A CAD design of a phone holder developed using AutoCAD.

## Design Objectives
- Create a functional phone support structure.
- Develop a 3D model of the design.
- Explore dimensions, proportions and structural features.

## Software Used
- AutoCAD
